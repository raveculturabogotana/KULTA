# KULTA

Sitio web de KULTA: cultura rave en Bogotá. Es un sitio estático (HTML + assets), sin paso de compilación.

- `index.html`: inicio
- `*.html`: una página por producto
- `assets/`: imágenes y videos

## Desplegar en Vercel
1. Entra a https://vercel.com/new con tu cuenta de GitHub.
2. Importa este repositorio (`KULTA`).
3. Framework Preset: **Other**. Deja vacíos *Build Command* y *Output Directory*.
4. Pulsa **Deploy**.

Esta copia se generó desde el proyecto de diseño en claude.ai. Los cambios que se hagan allá no llegan solos aquí: hay que volver a exportar.
